# Platformer Knight

A small 2D platformer I made in 2025 using the Godot Engine. This was one of my early game development projects, where I explored the basics of making a game using free assets.

## Play Online

You can play the game directly in your browser here:

**[Play Platformer Knight](https://iamsodeadxd.github.io/Platformer-Knight/)**

## About the Game

Platformer Knight is a simple 2D platformer where you control a knight and navigate through a level using platforming mechanics.

I made this project to get hands-on experience with Godot and learn how different scenes, scripts, and assets come together to create a playable game.

The game uses free assets and is deployed on GitHub Pages, so you can play it without downloading anything.

## Controls

| Key | Action |
|---|---|
| A | Move left |
| D | Move right |
| Space | Jump |
| Left Arrow | Move left |
| Right Arrow | Move right |
| Up Arrow | Jump |

## Download for Windows

A Windows executable is available in this repository for those who prefer to play locally.

Download the normal `.exe` file along with any required game data files from the repository.

## Running the Project in Godot

The repository contains exported game builds for web and Windows.

To edit the game in Godot, you will need the original project files, including `project.godot`, scenes, scripts, and assets.

## What I Learned

This project gave me my first hands-on experience with 2D game development in Godot. I learned about organizing scenes, working with scripts and free assets, setting up basic gameplay, and exporting a game for the web.

It was a small project, but it helped me get started with game development and gave me a foundation to build on in future projects.
